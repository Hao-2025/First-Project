# 🍚 The Rice Restaurant - Fried Rice Menu Website

Welcome to the official repository for **The Rice Restaurant** website. This website provides information about our fried rice menu, operating hours, and contact details.

---

## 📌 Features

- 📖 **User-Friendly & Intuitive**: Designed with a warm, welcoming color palette.
- 📋 **Rich Menu (`index.html`)**: Detailed pricing tables for meat, seafood fried rice, and side dishes.
- ⏰ **Opening Hours (`hours.html`)**: Clear business schedule throughout the week.
- 📞 **Contact Page (`contact.html`)**: Address details and contact form.
- 🎨 **Unified Styling**: Consistent look and feel managed through a single `style.css` stylesheet.

---

## 🛠️ Tech Stack

- **HTML5**: Page structure and semantic elements.
- **CSS3**: Layout, custom color scheme, and typography alignment.
- **Git & GitHub**: Version control and project repository hosting.
